# Contextual Alt Text

Write image alternatives from the supplied image, its purpose and surrounding text.

Copy the instructions in [SKILL.md](SKILL.md) into ChatGPT or Claude and supply the material you want reviewed. In an Agent Skills environment, install the folder with its original name.

## Example

A linked magnifier icon opens search and has no adjacent label.

Expected behavior: Use the control's purpose, such as Search, as its accessible name.
