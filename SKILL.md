# Contextual Alt Text

Identify the image's role in this specific placement. For a linked image describe the destination or action when the link lacks an accessible name. For a chart summarize the supported takeaway and identify where a longer data description is needed. For decorative images in HTML, suggest an empty alt value only when the adjacent content already conveys the meaning. Request the missing image or description when the subject is unknown.
